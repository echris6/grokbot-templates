# Caption playbook

A short-form caption has one job: get the viewer to watch again, comment or follow. The video does the rest.

## Shape

1. **First line (≤ 60 characters):** shown before "more". A reaction, a question or a deadpan line in the character's voice. Never a description of the video.
2. **Optional second line:** a comment prompt ("which one are you?", "rate his fit 1–10").
3. **Hashtags:** 3–5 total: 2 niche tags, 1 format tag (e.g. #pov), 1 tag with the character's name. No #fyp spam and no banned or unrelated trending tags.
4. **Optional credit:** "trend from @page" (only if `credit_trend_source` is on).

## The character's voice

The character card (`/workspace/ai-influencer/character/character.md`) holds 3 voice rules (e.g. "speaks like an 1890s butler", "never uses emojis except 🫖") and 5 example lines. Every caption follows them. Same voice every day is what turns a strange face into a recognisable character.

## Give 3 options

For each video, offer 3 captions: A **deadpan**, B **question/comment bait**, C **in-character one-liner**, each with its hashtags. The user picks or edits.

## Never

- Copy the source clip's caption, on-screen text or jokes word for word.
- Claim the character is a real person, or imply a real person said or did something.
- Promise results ("this will make you rich"), mention money the account made, or use fake numbers.
- Mention a brand unless it's a disclosed paid partnership. In that case the user turns on the platform's paid-partnership label.

## AI label reminder (goes under every caption, for the user only)

> Before posting: turn on the platform's AI-generated label. On Instagram that's the "AI info" label in Advanced settings; on TikTok it's the "AI-generated content" toggle under More options. Both platforms ask for it on realistic AI video, and either may add a label automatically when the file carries AI metadata (Gemini Omni output carries a SynthID watermark).

The platforms rename these settings often. If the label isn't where the reminder says, the user should look for "AI" in the post's advanced options.
