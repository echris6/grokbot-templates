# Launchpad setup

No plugins, no secrets and no routines. After installing:
1. Start a chat and say "help me pick a business".
2. The `launchpad-interview` skill runs. If it's missing from the `/` menu (a known import bug), ask: "Save the skill in /workspace/grokbot-templates/launchpad/skills/launchpad-interview/SKILL.md". If the kit isn't on the computer, clone it first:
   `git clone --depth 1 https://github.com/echris6/grokbot-templates /workspace/grokbot-templates`
